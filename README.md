# Raquel Teruel: Spanish lessons

The website of Raquel Teruel, a Spanish teacher (ELE) and official DELE examiner.

- Test address: https://rachel.geiser.cloud
- Plain static HTML and CSS, served by GitHub Pages from `main`. No build step, no cookies and no trackers.
- English lives at `/`, Spanish at `/es/`.

To change a text or a price, edit the HTML file and push to `main`. The site updates in about a minute.
